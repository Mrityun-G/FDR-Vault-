# FDR Vault — mobile redesign mockups

Static design mockups for the institution app, in one formal AICTE design system
(navy `#0A2347` / `#12366B`, white, light grey `#F3F5F8`, gold `#C9A13B`; Public Sans).

Open [`index.html`](index.html) in a browser to see every screen side by side, or open a screen on its own:

| Screen | File |
|---|---|
| Login | [`login.html`](login.html) |
| Registration | [`registration.html`](registration.html) |
| Institution dashboard | [`dashboard.html`](dashboard.html) |
| Applications | [`applications.html`](applications.html) |
| FDR / Security deposit | [`fdr.html`](fdr.html) |
| Notifications | [`notifications.html`](notifications.html) |
| Profile | [`profile.html`](profile.html) |
| Design system (colours, type, components) | [`design-system.html`](design-system.html) |

The bottom tabs and main buttons link between screens. Names and numbers are sample content from the app's
demo data; amounts and dates are illustrative. These files are mockups only — the live app (repository root)
is unchanged.
