Notes
  * Many cases CHANGE the data (approve, endorse, decide). Each can be run once.
    Run them in the order given; section 6 lists the order across portals.
  * "Unique" values (FDR numbers, emails) must not exist yet. If a case was run
    before, change the last digits (e.g. SBI-FDR-77120-2026 -> SBI-FDR-77130-2026).
  * Uploads need real files: any PDF, JPG or PNG up to 10 MB. Use a DIFFERENT
    file for each document (the same file twice is flagged as a duplicate).
  * Dates are entered as DD-MM-YYYY in the date picker; written here as YYYY-MM-DD.
  * Amounts are entered in rupees: Rs 1 Crore = 10000000, Rs 40 Lakhs = 4000000.

Field rules used by every form
  Mobile    : 10 digits starting with 6, 7, 8 or 9 (+91 prefix allowed)
  Email     : name@domain.tld
  Password  : 8+ characters with upper-case, lower-case, number and special character
  IFSC      : 4 letters + 0 + 6 letters/digits, e.g. SBIN0001234 (11 characters)
  FDR number: letters/digits, - or /, at least 6 characters, e.g. SBI-FDR-77120-2026
  FDR tenure: maturity date at least 10 years after the issue date
  Files     : PDF / JPG / PNG, max 10 MB each

Reference: banks and IFSC prefixes accepted by the bank check
  State Bank of India SBIN | Punjab National Bank PUNB | Canara Bank CNRB
  HDFC Bank Ltd HDFC | Bank of Baroda BARB | ICICI Bank Ltd ICIC
  Axis Bank Ltd UTIB | Union Bank of India UBIN
